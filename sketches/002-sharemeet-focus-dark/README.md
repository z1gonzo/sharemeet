## Variant: ShareMeet Focus Dark

### Design stance
Premium dark UI inspirowany Linear — dla nowoczesnego, technicznego produktu.

### Key choices
- Layout: pełny social screen z feedem, profilem i stanami backendu.
- Typography: Inter + JetBrains Mono / Linear-like.
- Color: near-black + indigo/emerald accent.
- Interaction: publish mock post, comments toggle, follow toggle, tab/category feedback.

### Trade-offs
- Strong at: premium feel, techniczne portfolio, mocna hierarchia.
- Weak at: może być zbyt techniczny dla masowego social portalu.

### Best for
- Wariant dla publicznego portfolio i nowoczesnego produktu social-tech.
