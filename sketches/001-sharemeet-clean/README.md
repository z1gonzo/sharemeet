## Variant: ShareMeet Clean

### Design stance
Jasny, bezpieczny MVP social feed — Notion-like, czytelność i prostota.

### Key choices
- Layout: pełny social screen z feedem, profilem i stanami backendu.
- Typography: Inter / Notion-like.
- Color: ciepła biel + niebieski CTA.
- Interaction: publish mock post, comments toggle, follow toggle, tab/category feedback.

### Trade-offs
- Strong at: bezpieczny MVP, czytelność, łatwe przejście do produkcyjnego frontendu.
- Weak at: mniej charakterystyczny wizualnie.

### Best for
- Pierwszy realny frontend ShareMeet, gdy chcemy szybko zbudować coś czytelnego i niebrzydkiego.
